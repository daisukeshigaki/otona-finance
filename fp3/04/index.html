FP3級 · 暮らしのお金と試験対策

4章：タックスプランニング（7講義）

所得の分類から控除・税額・申告まで、税金の計算順序を学ぶ。

講義カリキュラム

  1. 第1回：税金の全体像と所得税の仕組み

    国税・地方税、所得税の計算の流れを整理する。教材番号 4-01

    →
  2. 第2回：10種類の所得① 給与・事業・不動産など

    収入と所得を区別し、主な所得の計算方法を学ぶ。教材番号 4-02

    →
  3. 第3回：10種類の所得② 譲渡・一時・雑所得など

    資産の売却や保険の満期金などの所得区分を学ぶ。教材番号 4-03

    →
  4. 第4回：所得控除① 人・家族に関する控除

    基礎・配偶者・扶養などの控除と適用条件を整理する。教材番号 4-04

    →
  5. 第5回：所得控除② 保険料・医療費・寄附など

    社会保険料、生命保険料、医療費などの控除を比較する。教材番号 4-05

    →
  6. 第6回：税額控除・申告と住民税・法人税の基本

    住宅ローン控除、確定申告・年末調整と他の税金を学ぶ。教材番号 4-06

    →
  7. 第7回：タックスの総復習と所得税の計算演習

    収入→所得→課税所得→税額の順で計算する。教材番号 4-07

    →

この章は7講義、動画は合計約70分の予定です。この章の全講義の記事・図解・練習問題を公開しました。動画は未収録で、撮影後に追加します。
