5章：不動産（6講義）

物件の調査、取引、法令、税金をひとつの流れで理解する。

講義カリキュラム

  1. 第1回：不動産の調査・登記・価格

    登記簿、公示価格、相続税評価などの役割を区別する。教材番号 5-01

    →
  2. 第2回：不動産の売買・賃貸と借地借家法

    取引の手順、契約、仲介手数料、借り手の権利を学ぶ。教材番号 5-02

    →
  3. 第3回：都市計画法・建築基準法

    用途地域、建ぺい率、容積率と建築の制限を確認する。教材番号 5-03

    →
  4. 第4回：不動産の取得・保有にかかる税金

    不動産取得税、登録免許税、固定資産税などを整理する。教材番号 5-04

    →
  5. 第5回：不動産の譲渡・特例と有効活用

    売却益の税金と主な特例、活用方法の基本を学ぶ。教材番号 5-05

    →
  6. 第6回：不動産の総復習と計算演習

    建築面積、延べ面積、取引・税金の事例を確認する。教材番号 5-06

    →

この章は6講義、動画は合計約60分の予定です。この章の全講義の記事・図解・練習問題を公開しました。動画は未収録で、撮影後に追加します。
