2章：リスク管理（6講義）

生命保険・損害保険を、必要な保障と税金から読み解く。

講義カリキュラム

  1. 第1回：保険の仕組みと契約の基本

    保険料、告知、契約者・被保険者・受取人を区別する。教材番号 2-01

    →
  2. 第2回：生命保険の種類と特徴

    定期・終身・養老保険を、保障期間と満期保険金で比較する。教材番号 2-02

    →
  3. 第3回：医療・がん・介護保険と特約

    病気や介護への備えと、主契約・特約の関係を学ぶ。教材番号 2-03

    →
  4. 第4回：損害保険と第三分野の保険

    火災・地震・自動車・傷害保険の補償範囲を整理する。教材番号 2-04

    →
  5. 第5回：保険と税金・必要保障額

    保険金の課税関係と、家族に必要な保障を考える。教材番号 2-05

    →
  6. 第6回：リスク管理の総復習と事例演習

    契約の読み取り、保障の選択、税金の区分を確認する。教材番号 2-06

    →
