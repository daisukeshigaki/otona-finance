SITE GUIDE

このサイトの使い方

目的に合う講座を選び、具体例で理解し、問題を解いて確かめる。動画を待たずに、記事から学び始められます。

公開・更新：2026年9月17日

この記事で分かること
  1. 目的から講座を選ぶ
  2. 一つの講義を3段階で使う
  3. 制度・企業例は出典も確認する
  4. 質問や誤りの指摘をする
  5. 学んだ知識で、分析記事を読む

1. 目的から講座を選ぶ

迷ったら目的別の学習ロードマップへ。講義はメニューに公開済みの記事へのリンクがあります。準備中の教材や動画は、公開したものから追加します。

2. 一つの講義を3段階で使う

  • 読む：冒頭のゴールと目次で、今日理解することを確認する。
  • 確かめる：図表と具体例の数字を自分で計算する。
  • 解き直す：練習問題を解き、解説を閉じて理由を説明する。

動画が掲載されている講義は、記事と併せて使えます。「動画埋め込み枠」は動画が未公開の場所です。すべての講義動画が完成しているという意味ではありません。教材・講義動画は無料ですが、資格試験や公式講座の費用は別です。

3. 制度・企業例は出典も確認する

出典欄のリンクから原資料へ進めます。数値の単位、決算期、制度時点、架空の仮定を確認し、予想を実績として覚えないようにします。自分の生活や仕事に当てはめる際は、本人の条件と最新情報を調べてください。

4. 質問や誤りの指摘をする

講義のコメント欄には、ニックネームと疑問を書けます。運営者の確認・承認後に公開され、TOPの最近のコメントにも表示されることがあります。返信も公開されます。個人情報は書かないでください。

個別の返信が必要な相談、誤りの詳細、研修の依頼にはお問い合わせフォームを使い、ページURLと該当箇所を添えてください。個人情報の扱いと編集・訂正方針も確認できます。

5. 学んだ知識で、分析記事を読む

TOPの「市場・企業の分析を読む」からVoicestackへ進めます。現在は別ドメインのサイトです。金利や決算の記事で分からない言葉に出会ったら、関連講義へ戻り、概念を確認する使い方がおすすめです。

入口の疑問を扱うコラム一覧も用意しています。講義、コラム、分析を往復しながら、少しずつ説明できることを増やしていきましょう。
