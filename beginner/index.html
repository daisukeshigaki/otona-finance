初級編

PL・BS・CFを読み、企業の数字を具体例で理解する。

公開中の記事

  1. 第1回：会社とは・資本市場とは

    株式会社の役割と、お金を集める仕組み。出資・借入、発行市場・流通市場の違いを学ぶ。

    →
  2. 第2回：株価とは・企業価値とは

    株価・時価総額・EVの違いと、稼ぐ力・成長・資本コストから価値を考える。

    →
  3. 第3回：PLの見方

    売上から最終利益まで、利益が生まれる流れを企業の実例で読み解く。

    →
  4. 第4回：BSの見方

    資産・負債・純資産から、会社のお金の使い道と調達源を読み解く。

    →
  5. 第5回：CFの見方

    営業・投資・財務の現金の動きから、利益と手元のお金の違いを学ぶ。

    →
  6. 第6回：PL・BS・CFのつながり

    同じ取引を3つの表で追い、利益・資産・現金がどう動くかを理解する。

    →
  7. 第7回：PERとは何か

    株価を1株当たり利益で割り、価格と稼ぐ力の関係を読む。

    →
  8. 第8回：PBRとは何か

    株価と帳簿上の自己資本を比較し、1倍の意味と限界を理解する。

    →
  9. 第9回：株主価値と企業価値（EV）

    時価総額とEVを区別し、借入と現金を調整する理由を理解する。

    →
  10. 第10回：EBITDAとEV/EBITDA

    減価償却前の利益と事業価値を比較し、設備投資・現金との差まで読む。

    →
