COURSE CATALOG

初級編

PL・BS・CFを読み、企業の数字を具体例で理解する。

公開中の記事

  1. 第1回：会社とは・資本市場とは

    株式会社の役割と、お金を集める仕組み。出資・借入、発行市場・流通市場の違いを学ぶ。

    →
  2. 第2回：株価とは・企業価値とは

    株価・時価総額・EVの違いと、稼ぐ力・成長・資本コストから価値を考える。

    →
  3. 第3回：PLの見方

    売上から最終利益まで、利益が生まれる流れを企業の実例で読み解く。

    →
  4. 第4回：BSの見方

    資産・負債・純資産から、会社のお金の使い道と調達源を読み解く。

    →
  5. 第5回：CFの見方

    営業・投資・財務の現金の動きから、利益と手元のお金の違いを学ぶ。

    →
  6. 第6回：PL・BS・CFのつながり

    同じ取引を3つの表で追い、利益・資産・現金がどう動くかを理解する。

    →
  7. 第7回：PERとは何か

    株価を1株当たり利益で割り、価格と稼ぐ力の関係を読む。

    →
  8. 第8回：PBRとは何か

    株価と帳簿上の自己資本を比較し、1倍の意味と限界を理解する。

    →
  9. 第9回：株主価値と企業価値（EV）

    時価総額とEVを区別し、借入と現金を調整する理由を理解する。

    →
  10. 第10回：EBITDAとEV/EBITDA

    減価償却前の利益と事業価値を比較し、設備投資・現金との差まで読む。

    →
  11. 第11回：マルチプルの使い分け

    PER・PBR・EV/EBITDAを同じ会社で計算し、利益・純資産・事業価値の対応を整理する。

    →
  12. 第12回：ROE・ROAとは何か

    利益を自己資本と総資産で割り、資産の効率と借入の影響を分けて読む。

    →
  13. 第13回：ROICとは何か

    NOPATと投下資本を組み合わせ、株主と貸し手の資金が事業でどれだけ稼ぐかを読む。

    →
  14. 第14回：利益成長と再投資

    再投資率と追加投資の収益率から、売上の増加ではなく利益成長の質を読む。

    →
  15. 第15回：ROICとWACCの関係

    資本コストを超える利益を生むか、ROICスプレッドと経済利益で考える。

    →
  16. 第16回：資本コストとは何か

    お金を預けた人の要求収益と、将来のお金を現在価値に戻す割引率を理解する。

    →
  17. 第17回：CAPMとは何か

    無リスク金利・市場リスクプレミアム・βを分け、株主資本コストを計算する。

    →
  18. 第18回：βとは何か

    市場への感応度と株価全体のリスクを区別し、事業と借入がβに与える影響を読む。

    →
  19. 第19回：負債コストと節税効果

    利息・債券利回り・信用リスクを区別し、税引後の負債コストを計算する。

    →
  20. 第20回：WACCとは何か

    市場価値の構成比で資金コストを加重平均し、借入を増やす時の落とし穴を理解する。

    →
  21. 第21回：FCFとは何か

    営業利益からFCFFを作り、株主のFCFEと実際のCF計算書の簡便指標を区別する。

    →
  22. 第22回：NPVとIRRの使い分け

    投資が生む価値を金額と利回りで測り、規模の違う案件を正しく比較する。

    →
  23. 第23回：配当と配当政策

    配当利回り・配当性向・DOEを分け、増配の持続性と配当政策を企業実例で読む。

    →
  24. 第24回：株主優待とは何か

    券面額と自分の利用価値を分け、保有条件・通常優待・特別優待を正しく確認する。

    →
