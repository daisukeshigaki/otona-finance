FP・簿記・CMAの違い――目的別にどれから学ぶか

3つは競争する資格というより、違う問いに答えるための学習です。この記事ではFP3級、日商簿記3級、CMAを比較します。

執筆・編集：おとなのファイナンス · 公開・更新：2026年9月17日

この記事で分かること
  1. 暮らし・記録・分析の違い
  2. 同じ住宅・会社の話でも、見る角度が違う
  3. 目的から最初の学習を選ぶ
  4. 費用や期間は、単純なランキングにしない
  5. 当サイトでの入口

1. 暮らし・記録・分析の違い

FPと書かれた資格には複数の種類があり、簿記も級や実施団体によって範囲が違います。この比較をそのままFP1級や簿記1級まで一般化しないようにします。

2. 同じ住宅・会社の話でも、見る角度が違う

住宅購入を考えるなら、家計の支出やローン、保険、税を整理するFPの視点が入口になります。会社が建物を取得した取引をどう記録するかなら簿記、その投資が将来CFと資本コストに見合うかならファイナンス分析の視点です。

同じ「お金の話」でも、生活の選択、会計処理、価値の評価は違う作業です。一つを学べば残りを全部代替できるわけではありません。

3. 目的から最初の学習を選ぶ

  • 自分の家計や制度を理解したい：FP3級から。
  • 仕事で帳簿や仕訳に触れる：日商簿記3級の範囲から。
  • 決算や株式投資の理解を始めたい：初心者編・初級編で財務の地図を作る。
  • 投資分析を体系的に深めたい：CMAの公式制度と学習範囲を確認する。

簿記3級やFP3級の取得がCMA受講の必須条件という意味ではありません。現在の知識と目的に応じて、必要な基礎を補うための順番です。

4. 費用や期間は、単純なランキングにしない

FP・簿記の検定と、必須の教育講座を含むCMAでは制度が違います。受験料だけでなく講座、教材、入会等の対象を確認します。勉強期間も経験、使える時間、受験可能年度で変わるので、「何週間で誰でも取れる」とは言えません。

資格がないと知識を学べないわけでもありません。生活への活用が目的なら必要な章から学び、資格取得が目標になった段階で公式範囲と演習を追加できます。

5. 当サイトでの入口

FP3級講座、初心者編、初級編、CMA講座を公開しています。簿記講座は準備中です。日商簿記の受験内容は日本商工会議所の案内を確認してください。

迷ったら目的別の学習ロードマップで、自分が答えたい疑問から選びましょう。

出典・公式の確認先

確認日：2026年9月17日。制度・申込条件等は変更される場合があります。行動前に公式の最新案内を確認してください。

  • 日本FP協会：FPの知識を身につける
  • 日本商工会議所：日商簿記3級
  • 日本証券アナリスト協会：資格・教育体系

一般的な学習情報であり、個別の投資・税務・法律助言ではありません。架空例の数字は説明用の仮定です。資格の取得や投資成果を保証するものではありません。
