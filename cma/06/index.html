講義カリキュラム

  1. 第1回：期待リターン・分散・標準偏差

    期待リターンは起こり得る収益率を確率で加重平均した値です。具体例と条件を変えた例で、期待リターン・分散・標準偏差を学ぶ。教材番号 6-01

    →
  2. 第2回：共分散・相関と分散効果

    共分散は二資産の平均からのずれが一緒に動く程度です。具体例と条件を変えた例で、共分散・相関と分散効果を学ぶ。教材番号 6-02

    →
  3. 第3回：2資産・多資産ポートフォリオ

    ポートフォリオ収益は重み付き平均ですが、分散には資産同士の共分散が必要です。具体例と条件を変えた例で、2資産・多資産ポートフォリオを学ぶ。教材番号 6-03

    →
  4. 第4回：効率的フロンティア

    効率的フロンティアは同じリスクで最大の期待収益、または同じ期待収益で最小のリスクとなる組合せの集合です。具体例と条件を変えた例で、効率的フロンティアを学ぶ。教材番号 6-04

    →
  5. 第5回：投資家効用・リスク回避度

    リスク回避度は不確実性をどれほど嫌うかを表します。具体例と条件を変えた例で、投資家効用・リスク回避度を学ぶ。教材番号 6-05

    →
  6. 第6回：無リスク資産・資本市場線

    資本市場線CMLは無リスク資産と市場ポートフォリオを組み合わせた効率的な関係です。具体例と条件を変えた例で、無リスク資産・資本市場線を学ぶ。教材番号 6-06

    →
  7. 第7回：CAPM・証券市場線

    CAPMは市場と連動するリスクで必要期待収益を表すモデルです。具体例と条件を変えた例で、CAPM・証券市場線を学ぶ。教材番号 6-07

    →
  8. 第8回：ベータとシステマティックリスク

    ベータは市場収益との共分散を市場分散で割った感応度です。具体例と条件を変えた例で、ベータとシステマティックリスクを学ぶ。教材番号 6-08

    →
  9. 第9回：単一指数／マルチファクターモデル

    単一指数モデルは市場要因と残差、マルチファクターモデルは複数の共通要因で収益を分解します。具体例と条件を変えた例で、単一指数／マルチファクターモデルを学ぶ。教材番号 6-09

    →
  10. 第10回：市場効率性

    市場効率性は情報が価格へどの程度反映されるかという仮説です。具体例と条件を変えた例で、市場効率性を学ぶ。教材番号 6-10

    →
  11. 第11回：パッシブ・アクティブ運用

    パッシブ運用は指数等への追随、アクティブ運用は相対的超過収益等を目指す運用です。具体例と条件を変えた例で、パッシブ・アクティブ運用を学ぶ。教材番号 6-11

    →
  12. 第12回：ファクター投資・スマートベータ

    ファクター投資は価値、規模、モメンタム等の属性へのエクスポージャーを設計します。具体例と条件を変えた例で、ファクター投資・スマートベータを学ぶ。教材番号 6-12

    →
  13. 第13回：シャープ・トレイナー・ジェンセンα・情報比率

    シャープは超過収益/総σ、トレイナーは超過収益/β、ジェンセンαはCAPM必要率との差、情報比率IRは対ベンチマーク超過収益/追随誤差です。具体例と条件を変えた例で、シャープ・トレイナー・ジェンセンα・情報比率を学ぶ。教材番号 6-13

    →
  14. 第14回：アクティブ運用の基本法則

    アクティブ運用の基本法則は、情報係数ICと独立な意思決定数BRからIR≈IC√BRを考える関係です。具体例と条件を変えた例で、アクティブ運用の基本法則を学ぶ。教材番号 6-14

    →
  15. 第15回：スタイル分析・マネジャー評価

    スタイル分析は運用の株式・債券や価値・成長等への偏りを確認します。具体例と条件を変えた例で、スタイル分析・マネジャー評価を学ぶ。教材番号 6-15

    →
  16. 第16回：VaR・Expected Shortfall・ストレステスト

    VaRは一定期間・信頼水準の損失分位点、Expected Shortfallはその尾部の平均損失を表す指標です。具体例と条件を変えた例で、VaR・Expected Shortfall・ストレステストを学ぶ。教材番号 6-16

    →
  17. 第17回：ドローダウン・破産確率・ポジションサイズ

    ドローダウンは資産の過去ピークからの減少率です。具体例と条件を変えた例で、ドローダウン・破産確率・ポジションサイズを学ぶ。教材番号 6-17

    →
  18. 第18回：リスク予算・リバランス

    リスク予算は各資産・戦略が全体リスクへ与える寄与を配分する考え方です。具体例と条件を変えた例で、リスク予算・リバランスを学ぶ。教材番号 6-18

    →
  19. 第19回：行動ファイナンス：期待効用とプロスペクト理論

    期待効用理論は資産状態の効用を確率で平均します。具体例と条件を変えた例で、行動ファイナンス：期待効用とプロスペクト理論を学ぶ。教材番号 6-19
