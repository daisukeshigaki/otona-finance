5章：デリバティブ（17講義）

全17講義の記事・図表・練習問題を公開しました。動画は撮影後に追加します。

講義カリキュラム

  1. 第1回：デリバティブの役割・上場／OTC

    上場デリバティブは取引所の標準化された契約、OTCは当事者間で設計する契約です。具体例と条件を変えた例で、デリバティブの役割・上場／OTCを学ぶ。教材番号 5-01

    →
  2. 第2回：フォワード・先物の損益と証拠金

    フォワードと先物は将来の売買価格を決める契約です。具体例と条件を変えた例で、フォワード・先物の損益と証拠金を学ぶ。教材番号 5-02

    →
  3. 第3回：先物価格と無裁定・キャリーコスト

    先物価格は現物と調達・保管・収入を対応させる無裁定関係で考えます。具体例と条件を変えた例で、先物価格と無裁定・キャリーコストを学ぶ。教材番号 5-03

    →
  4. 第4回：株価指数先物・債券先物・為替フォワード

    株価指数先物は株式市場、債券先物は金利、為替フォワードは通貨の変化を移す契約です。具体例と条件を変えた例で、株価指数先物・債券先物・為替フォワードを学ぶ。教材番号 5-04

    →
  5. 第5回：スワップ：金利・通貨スワップ

    金利スワップは固定金利と変動金利などのCFを交換します。具体例と条件を変えた例で、スワップ：金利・通貨スワップを学ぶ。教材番号 5-05

    →
  6. 第6回：オプション：コール・プット・満期損益

    コールは決まった価格で買う権利、プットは売る権利です。具体例と条件を変えた例で、オプション：コール・プット・満期損益を学ぶ。教材番号 5-06

    →
  7. 第7回：プット・コール・パリティ

    プット・コール・パリティは同じ原資産・行使価格・満期の欧州型コールとプットを現物と割引債に対応させる関係です。具体例と条件を変えた例で、プット・コール・パリティを学ぶ。教材番号 5-07

    →
  8. 第8回：オプション価格を決める要因

    オプション価格は株価、行使価格、残存期間、ボラティリティ、金利、配当等に影響されます。具体例と条件を変えた例で、オプション価格を決める要因を学ぶ。教材番号 5-08

    →
  9. 第9回：二項モデルによるオプション評価

    二項モデルでは上昇・下落状態で同じ受取となる複製ポートフォリオを作って権利を評価します。具体例と条件を変えた例で、二項モデルによるオプション評価を学ぶ。教材番号 5-09

    →
  10. 第10回：Black-Scholesの直感

    Black-Scholesモデルの式を、同じ株価・行使価格の具体例で計算する。ボラティリティを変えた場合も比較する。教材番号 5-10

    →
  11. 第11回：デルタ・ガンマ・ベガ・シータ・ロー

    グリークスはオプション価値の入力に対する局所感応度です。具体例と条件を変えた例で、デルタ・ガンマ・ベガ・シータ・ローを学ぶ。教材番号 5-11

    →
  12. 第12回：ボラティリティ・インプライドVol・Volスマイル

    実現Volは観測された収益率から計算する変動性、インプライドVolは市場オプション価格から逆算するモデル入力です。具体例と条件を変えた例で、ボラティリティ・インプライドVol・Volスマイルを学ぶ。教材番号 5-12

    →
  13. 第13回：代表的オプション戦略

    オプション戦略は複数の権利や現物を組み合わせて損益の形を変えます。具体例と条件を変えた例で、代表的オプション戦略を学ぶ。教材番号 5-13

    →
  14. 第14回：ヘッジ：株価・金利・為替・商品

    ヘッジでは対象の株価、金利、為替、商品リスクを測って逆向きの契約を選びます。具体例と条件を変えた例で、ヘッジ：株価・金利・為替・商品を学ぶ。教材番号 5-14

    →
  15. 第15回：実践：デリバティブでリスクを組み替える

    実践では事業の支払リスクを先渡とオプションで比較し、固定と保険の違いを説明します。具体例と条件を変えた例で、実践：デリバティブでリスクを組み替えるを学ぶ。教材番号 5-15

    →
  16. 第16回：金利デリバティブ：金利先物・FRA・Cap/Floor/Collar・Swaption

    FRAは将来区間の金利を固定する契約、キャップは上限、フロアは下限を作る権利です。具体例と条件を変えた例で、金利デリバティブ：金利先物・FRA・Cap/Floor/Collar・Swaptionを学ぶ。教材番号 5-16

    →
  17. 第17回：CDSと信用デリバティブ

    CDSは所定の信用事由に対する保護を売買する契約です。具体例と条件を変えた例で、CDSと信用デリバティブを学ぶ。教材番号 5-17

    →
