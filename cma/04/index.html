講義カリキュラム

  1. 第1回：債券の基本・割引債・固定利付債

    債券は発行者にお金を貸し、契約に従って利息と元本を受け取る証券です。具体例と条件を変えた例で、債券の基本・割引債・固定利付債を学ぶ。教材番号 4-01

    →
  2. 第2回：債券市場・発行市場・流通市場・レポ

    発行市場では発行者が資金を調達し、流通市場では既存保有者が債券を売買します。具体例と条件を変えた例で、債券市場・発行市場・流通市場・レポを学ぶ。教材番号 4-02

    →
  3. 第3回：債券価格・クーポン・YTM・経過利息

    YTMは購入価格と将来の約束CFを一致させる単一の利回りです。具体例と条件を変えた例で、債券価格・クーポン・YTM・経過利息を学ぶ。教材番号 4-03

    →
  4. 第4回：スポットレートと債券価格

    スポットレートは、特定の将来時点の一回のCFを現在へ割り引く利率です。具体例と条件を変えた例で、スポットレートと債券価格を学ぶ。教材番号 4-04

    →
  5. 第5回：フォワードレート・パーレート

    フォワードレートは、現在の期間構造が示す将来区間の利率です。具体例と条件を変えた例で、フォワードレート・パーレートを学ぶ。教材番号 4-05

    →
  6. 第6回：ブートストラップ

    ブートストラップは短い満期の割引係数から順に長い満期の係数を求める方法です。具体例と条件を変えた例で、ブートストラップを学ぶ。教材番号 4-06

    →
  7. 第7回：イールドカーブと期間構造理論

    イールドカーブは満期ごとの利回りを並べたものです。具体例と条件を変えた例で、イールドカーブと期間構造理論を学ぶ。教材番号 4-07

    →
  8. 第8回：スワップレート・カーブ

    金利スワップの固定レートは、固定脚と変動脚の現在価値を一致させるように決まります。具体例と条件を変えた例で、スワップレート・カーブを学ぶ。教材番号 4-08

    →
  9. 第9回：Zスプレッド・ASW・OAS

    Zスプレッドは基準の各スポット金利に同じ幅を加え、価格を再現する値です。具体例と条件を変えた例で、Zスプレッド・ASW・OASを学ぶ。教材番号 4-09

    →
  10. 第10回：変動利付債・インフレ連動債

    変動利付債は参照金利等に連動してクーポンが変わり、インフレ連動債は物価指数に応じて元本等が調整されます。具体例と条件を変えた例で、変動利付債・インフレ連動債を学ぶ。教材番号 4-10

    →
  11. 第11回：マコーレー／修正デュレーション

    マコーレーデュレーションはCF現在価値の重み付き平均回収時間です。具体例と条件を変えた例で、マコーレー／修正デュレーションを学ぶ。教材番号 4-11

    →
  12. 第12回：実効デュレーション・キーレートデュレーション

    実効デュレーションは金利を動かして再評価した価格から感応度を求めます。具体例と条件を変えた例で、実効デュレーション・キーレートデュレーションを学ぶ。教材番号 4-12

    →
  13. 第13回：コンベクシティ

    コンベクシティは価格と利回りの曲線の曲がり具合です。具体例と条件を変えた例で、コンベクシティを学ぶ。教材番号 4-13

    →
  14. 第14回：所有期間利回り・キャリー・ロールダウン

    所有期間利回りは保有中の利息、価格差、再投資等を購入価格に対応させた収益です。具体例と条件を変えた例で、所有期間利回り・キャリー・ロールダウンを学ぶ。教材番号 4-14

    →
  15. 第15回：金利モデル・二項モデルの直感

    金利二項モデルは将来金利の上昇・低下という枝を置き、将来価値をリスク中立確率で平均して現在へ戻す方法です。具体例と条件を変えた例で、金利モデル・二項モデルの直感を学ぶ。教材番号 4-15

    →
  16. 第16回：コーラブル債・プッタブル債

    コーラブル債は発行者が早期償還を選べる債券、プッタブル債は保有者が返済を請求できる債券です。具体例と条件を変えた例で、コーラブル債・プッタブル債を学ぶ。教材番号 4-16

    →
  17. 第17回：転換社債・キャップ／フロア付き債

    転換社債は条件に従って社債を株式へ転換できる証券です。具体例と条件を変えた例で、転換社債・キャップ／フロア付き債を学ぶ。教材番号 4-17

    →
  18. 第18回：信用リスク・信用格付・クレジットスプレッド

    信用リスクは債務者が契約を履行しないリスクです。具体例と条件を変えた例で、信用リスク・信用格付・クレジットスプレッドを学ぶ。教材番号 4-18

    →
  19. 第19回：構造型／誘導型信用リスクモデルの直感

    構造型モデルは企業資産価値と負債の関係からデフォルトを考えます。具体例と条件を変えた例で、構造型／誘導型信用リスクモデルの直感を学ぶ。教材番号 4-19

    →
  20. 第20回：証券化：SPV・トランチング

    証券化は資産のCFをSPV等で束ね、優先順位の違うトランチへ配分する仕組みです。具体例と条件を変えた例で、証券化：SPV・トランチングを学ぶ。教材番号 4-20

    →
  21. 第21回：RMBS・CMBS・MBS・期限前償還

    RMBSは住宅ローン、CMBSは商業不動産ローン等を基礎とする証券化商品です。具体例と条件を変えた例で、RMBS・CMBS・MBS・期限前償還を学ぶ。教材番号 4-21

    →
  22. 第22回：ABS・証券化商品のクレジット分析

    ABSの分析では基礎資産の延滞、損失、回収、期限前返済に加え、サービサーや信用補完を調べます。具体例と条件を変えた例で、ABS・証券化商品のクレジット分析を学ぶ。教材番号 4-22

    →
  23. 第23回：債券ポートフォリオ：インデックス・ラダー

    債券インデックス運用は指数の構成・期間・信用に近づけます。具体例と条件を変えた例で、債券ポートフォリオ：インデックス・ラダーを学ぶ。教材番号 4-23

    →
  24. 第24回：イールドカーブ戦略・クレジット戦略

    カーブ戦略は金利の水準、傾き、曲率等の変化を利用し、クレジット戦略は信用スプレッド等の変化を扱います。具体例と条件を変えた例で、イールドカーブ戦略・クレジット戦略を学ぶ。教材番号 4-24

    →
  25. 第25回：実践：金利1%変化と債券ポートフォリオ

    実践では保有額と金利感応度からショック時の損失を計算し、ヘッジ量と残るリスクを説明します。具体例と条件を変えた例で、実践：金利1%変化と債券ポートフォリオを学ぶ。教材番号 4-25
