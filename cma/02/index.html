2章：コーポレート・ファイナンス（23講義）

全23講義の記事・図表・練習問題を公開しました。動画は撮影後に追加します。

講義カリキュラム

  1. 第1回：現在価値・将来価値・割引率

    今日の100万円と一年後の100万円は同じ価値ではない。時間軸を描いて、複利と割引を逆向きに計算します。教材番号 2-01

    →
  2. 第2回：年金現価・永久年金・成長永久年金

    毎年もらうお金、永遠にもらうお金、少しずつ増えるお金。それぞれの現在価値と使える条件を整理する。教材番号 2-02

    →
  3. 第3回：NPVとIRR

    案件を選ぶ基準は、率の高さだけではない。NPVとIRRが違う結論を出す理由を数字で見る。教材番号 2-03

    →
  4. 第4回：投資案件のCF：埋没費用・機会費用・運転資本

    調査費をもう払った、土地は元から持っている。それでも投資判断に入れるCFと入れないCFを分ける。教材番号 2-04

    →
  5. 第5回：リスクと期待リターン

    期待リターンは約束ではない。二つの景気シナリオから平均・ばらつき・分散投資を読み解く。教材番号 2-05

    →
  6. 第6回：CAPMと株主資本コスト

    株主が求める収益率を、安全利率・市場リスクプレミアム・ベータに分けて計算する。教材番号 2-06

    →
  7. 第7回：ベータ：レバード／アンレバード

    借入の多い比較企業のベータを、そのまま自社へ使わない。事業リスクと財務レバレッジを分ける。教材番号 2-07

    →
  8. 第8回：WACCと税引後負債コスト

    株式と借入のコストを時価の重みでまとめる。税引後負債コストとCFの対応を確認する。教材番号 2-08

    →
  9. 第9回：ROIC > WACCと企業価値

    成長しても価値を壊すことがある。ROICとWACCの差から、投資の価値創造を考える。教材番号 2-09

    →
  10. 第10回：MM命題：資本構成の基礎

    借入で資金コストが安くなるなら、なぜ全部借金にしないのか。まずMMの理想世界を理解する。教材番号 2-10

    →
  11. 第11回：税効果・財務危機コスト・最適資本構成

    借入には税節約があるが、資金難にもコストがある。企業価値を押し上げる効果と下げる効果を並べる。教材番号 2-11

    →
  12. 第12回：エージェンシー問題・情報の非対称性

    会社の意思決定は誰のためか。過大投資・リスク転嫁・情報格差を、利害関係者の取り分で見る。教材番号 2-12

    →
  13. 第13回：資金調達：株式・社債・借入・転換証券

    株式・社債・借入・転換証券は、返済義務と支配権が違う。調達額だけでなく条件を比較する。教材番号 2-13

    →
  14. 第14回：配当・自社株買い・内部留保とペイアウト政策

    配当と自社株買いはお金を返す方法。EPSが上がることと、価値が増えることを切り分ける。教材番号 2-14

    →
  15. 第15回：成長投資・再投資率・サステイナブル成長

    伸びる売上には設備・在庫・債権が必要。成長率と再投資率を、利益率と資本効率へつなげる。教材番号 2-15

    →
  16. 第16回：M&A：シナジー・買収価格・増分ROIC

    買収で売上は増える。でも払い過ぎれば価値は減る。シナジー・プレミアム・統合費用を同じ時点で比較する。教材番号 2-16

    →
  17. 第17回：リアルオプションと不確実性

    今すぐ全部投資するだけが選択ではない。待つ・拡張する・撤退する権利が持つ価値を考える。教材番号 2-17

    →
  18. 第18回：実践：経営者なら100億円をどう配分するか

    経営者として100億円を配分する。成長投資・買収・返済・還元・資金余力を一つの表で比較する。教材番号 2-18

    →
  19. 第19回：プロジェクトファイナンス入門：SPV・ノンリコース・DSCR・ウォーターフォール

    発電所などのプロジェクトを別会社で運営し、事業CFから返済する仕組み。DSCRと支払順位を学ぶ。教材番号 2-19

    →
  20. 第20回：株式会社制度・会社法・所有と経営・IR

    株式会社では誰が資金を出し、誰が決め、誰が監督するのか。株主総会・取締役会・IRを整理する。教材番号 2-20

    →
  21. 第21回：事業戦略・コーポレートガバナンス

    戦略の言葉を利益・資本・CFへつなげる。ガバナンスが資本配分を監督する意味を考える。教材番号 2-21

    →
  22. 第22回：投資評価法の比較：PI・回収期間法・ARR・EVA/MVA

    NPV・IRR以外の評価法は何を測るのか。回収の速さ・会計利益・経済価値を混ぜずに比較する。教材番号 2-22

    →
  23. 第23回：事業・財務レバレッジ、短期資金繰り、ERM

    売上減少は利益に何倍効くか、さらに利息でどう増幅するか。利益のレバレッジと資金繰りを分ける。教材番号 2-23

    →
