リスクと期待リターン

期待リターンは約束ではない。二つの景気シナリオから平均・ばらつき・分散投資を読み解く。

教材番号 2-05 · CORE · 更新・基準確認：2026年9月17日 · 動画：約10分を予定（未収録）

この講義のゴール

確率加重の期待値を計算し、単独リスクとポートフォリオのリスクを区別できる。

  3. 逆に動く資産を組み合わせる
  4. 市場全体のリスクは残る
  5. 練習問題

1. 平均は確率で重みを付ける

架空株式Aは好況で20％、不況で−10％、各確率50％とします。期待リターンは20％×0.5＋（−10％）×0.5＝5％。実際のどちらの状態にも5％という結果はありません。確率が等しくないなら、単純平均ではなく確率を掛けて足します。

確率は予測上の仮定であり、過去の頻度を将来確率と同一視しません。配当込みか価格変化だけか、年率か月率かも統一します。過去の実現収益率の平均と、将来要求する収益率と、シナリオの期待収益率は、似た数字でも役割が違います。

2. ばらつきを分散と標準偏差で測る

Aの期待値5％から、好況は＋15ポイント、不況は−15ポイント離れています。確率分布の分散は偏差の二乗の確率加重和。小数で0.5×0.15²＋0.5×（−0.15）²＝0.0225、標準偏差は√0.0225＝15％です。

これは既知の二状態分布の計算で、観測データから標本分散を推計するn−1の式とは異なります。標準偏差は上振れもリスクとして数えます。損失を重視する場合は下方リスクやストレス損失も合わせて検討し、ばらつき一つで安全性を断定しません。

3. 逆に動く資産を組み合わせる

Bは好況−10％・不況20％、確率は同じ。AとBを50％ずつ持つと、どちらの状態でも5％です。この二状態モデルでは完全な逆相関なので分散がゼロになります。個々の標準偏差15％を単純に加重平均して15％とするのは誤りです。

実際の相関は推計誤差があり、危機時に高まることもあります。価格データで見えない流動性や信用リスクが消えるわけではありません。分散投資は構成銘柄数だけでなく、同じ需要・通貨・金利に依存していないかを見ることが大切です。

4. 市場全体のリスクは残る

個別企業の工場事故や製品失敗による固有リスクは、銘柄分散で軽減できます。一方、景気・市場金利など広く共通するリスクは分散しても残ります。CAPMは市場共通リスクへの感応度をベータで表し、要求リターンにつなぐモデルです。

期待リターンが高い資産でも、既存保有と同じ方向に大きく動けば全体のリスクを増やします。「リスクが高いから必ず儲かる」のではなく、投資家が補償を要求するという話です。損失許容額・資金の使用時期・分散の現実性を確認してから、収益率を比較します。

練習問題

必要な条件・数値・計算式は各問に記載しています。計算問題は電卓を使って構いません。本サイト独自の問題で、公式試験問題ではありません。

問1：期待値

好況リターン20％・確率50％、不況−10％・50％。期待値＝各リターン×確率の和。

期待リターンは？

答えと考え方を見る

5％。

問2：標準偏差

確率50％ずつでリターン20％・−10％、期待値5％。分散＝0.5×0.15²＋0.5×（−0.15）²。標準偏差＝分散の平方根。

標準偏差は？

答えと考え方を見る

15％。

問3：分散投資

好況：A20％・B−10％、不況：A−10％・B20％。両資産に50％ずつ。ポートフォリオ収益＝各収益の加重和。

両状態のリターンは？

答えと考え方を見る

どちらも5％。このモデル内では標準偏差0％です。
