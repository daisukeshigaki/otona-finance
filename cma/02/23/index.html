事業・財務レバレッジ、短期資金繰り、ERM

売上減少は利益に何倍効くか、さらに利息でどう増幅するか。利益のレバレッジと資金繰りを分ける。

教材番号 2-23 · CORE · 更新・基準確認：2026年9月17日 · 動画：約10分を予定（未収録）

この講義のゴール

DOL・DFLを計算し、短期資金繰りと全社リスク管理へつなげられる。

1. 固定費で利益の振幅が広がる

架空会社の売上100、変動費60、固定費20（百万円）なら限界利益40、EBIT20。営業レバレッジDOL＝限界利益÷EBIT＝2倍です。単価・変動費率・固定費が一定なら、売上が1％変わる近傍でEBITが約2％変わる関係を示します。

売上が10％落ちると売上90・変動費54・固定費20でEBIT16、20％減です。ただし価格や費用構造が変われば同じ倍率は使えません。利益がゼロ付近では指標が極端になるので、比率だけでなく損失額と損益分岐点も確認します。

2. 利息が株主利益をさらに増幅する

支払利息5、他の営業外損益なしならEBT15。財務レバレッジDFL＝EBIT÷EBT＝20/15＝約1.33倍、総合レバレッジDTL＝DOL×DFL＝約2.67倍。税率一定・優先配当等なしの簡略条件で税引後利益の変化へ対応します。

元本返済はEBTから引きませんが、資金繰りには必要です。変動金利なら利息自体も動きます。DOL・DFLは一つの操業点での感応度なので、大幅な需要変化や赤字状態へ機械的に延長せず、直接PLとCFを計算して確認します。

3. 黒字でも現金の底を見る

月初現金10、当月回収30、仕入等支払25、給与等10、元本返済8（百万円）なら月末−3。黒字かどうかとは別に短期資金不足です。回収・支払・納税・設備・返済を日付順に並べ、月末だけでなく途中の最小残高を把握します。

入金見込みが遅れた場合も計算します。借入枠があっても財務制限条項で使えないことがあるので、未使用額だけでは安心できません。長期投資のNPVが正でも短期の支払日に資金が足りなければ実行できないという二つの時間軸を意識します。

4. ERMはリスクを全社でつなげる

ERMは市場・信用・流動性・事務・法務などのリスクを横断して扱います。為替ヘッジが市場リスクを減らしても担保差入れで流動性負担を増やすことがあります。各部門が別々に最適化するのではなく、許容度、責任、限度、報告を整えます。

保険やヘッジで完全にリスクが消えるわけではありません。相手先、基差、契約免責、オペレーションが残ります。売上から利益への倍率、利息の増幅、入出金の底、全社リスクの連鎖を一枚にまとめれば、第2章の財務判断を実務へつなげられます。

5. 企業実例：増収で販管費率が下がる

同社の国内ユニクロ事業の2026年8月期第3四半期三カ月では売上収益2,859億円、事業利益622億円。前年同期比は売上10.0％増、事業利益18.3％増です。ここでの指標は会社定義の「事業利益」で、EBITや営業利益へ無条件に置き換えません。

利益成長率/売上成長率は1.83ですが、これを厳密なDOLと呼ぶことはできません。価格、商品構成、費用の変化を含む実績だからです。固定費一定の架空モデルと、実際の利益増幅を観察するケースを分け、どこまで数字から言えるかを確認します。

練習問題

必要な条件・数値・計算式は各問に記載しています。計算問題は電卓を使って構いません。本サイト独自の問題で、公式試験問題ではありません。

問1：DOL

売上100・変動費60・固定費20。限界利益＝売上−変動費、EBIT＝限界利益−固定費、DOL＝限界利益÷EBIT。

DOLは？

答えと考え方を見る

40÷20＝2倍。

問2：売上減少

売上90、変動費率60％、固定費20、利息5。EBT＝売上−変動費−固定費−利息。

EBTは？

答えと考え方を見る

90−54−20−5＝11。

問3：資金不足

月初現金10、回収30、仕入支払25、給与等10、元本返済8（百万円）。他CFなし。月末＝月初＋入金−支出。

月末残高と不足は？

答えと考え方を見る

−3百万円、不足3百万円。
