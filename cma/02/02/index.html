年金現価・永久年金・成長永久年金

毎年もらうお金、永遠にもらうお金、少しずつ増えるお金。それぞれの現在価値と使える条件を整理する。

教材番号 2-02 · CORE · 更新・基準確認：2026年9月17日 · 動画：約10分を予定（未収録）

年金・永久年金のCF時点を説明し、成長率と割引率の条件を確認できる。

1. 年金は毎期同額のCF

金融でいう年金は、公的年金だけでなく毎期同額のキャッシュ・フローです。普通年金は各期末、期首年金は各期初に受け取ります。ここでは初回が一年後の普通年金、年割引率10％。三年間に各10万円を受け取る架空契約を考えます。

年金現価係数は［1−（1＋r）^−n］÷rです。同額CFにこの係数を掛ければ、毎年の割引をまとめられます。r＝0のときはこの分数を使わずCF×n。期首年金なら全体が一期間早くなるため、普通年金価値に1＋rを掛けます。

2. 永久年金には終わりがない

来年末から毎年10万円が永久に続き、割引率10％ならPV＝C÷r＝100万円です。100年分を単純に足す式ではなく、無限の割引CFの和です。資産に寿命がある、支払能力がない、途中で条件が変わるならそのまま永久年金にはできません。

Cは一期後のCFです。今すぐもらう10万円が別にあるなら、100に10を足して110万円。永続する企業の評価でも、更新投資や費用を無視して配当・CFが永遠に一定と決めるのは危険です。モデルの前提を先に言葉で確認します。

3. 成長永久年金はr＞g

初回CF10万円、以後毎年2％成長、割引率10％ならPV＝C1÷（r−g）＝125万円です。C1は一年後のCFであり、今年のCFではありません。今日の基準CFが10ならC1＝10.2となり、価値127.5万円です。

gがrに近づくと分母が小さくなり価値が急増します。g≧rならこのモデルの現在価値は収束せず、負の値を「割安」と読むのは誤りです。短期の高成長を永続成長に流用せず、安定期の投資負担と経済規模も検討します。

4. 時点の一つのずれが価値を変える

五年目以降に永久CFが始まる場合、公式で得た値は初回CFの一つ前、四年末の価値です。そこから四回割り引いて今日へ戻します。「永久CFの価値」と書くだけでは評価時点が不明なので、必ず何年末の値かを添えます。

三年分の詳細予測と四年目以降の永久年金を組み合わせるなら、四年目のCFを三年末で評価します。三年目のCFを永久年金にも入れると二重計上です。図の矢印を年末に置き、詳細予測の最後と永久CFの最初が重ならないことを確認します。

問1：三年年金

各年末10万円を3年、割引率10％。PV＝10÷1.1＋10÷1.1²＋10÷1.1³。

現在価値は？

答えと考え方を見る

約24.87万円。

問2：成長永久年金

一年後CF10万円、永続成長2％、割引10％。PV＝C1÷（r−g）、r＞g。

現在価値は？

答えと考え方を見る

125万円。

問3：今期と来期

今期CF10万円、翌年から毎年2％成長、割引10％。C1＝C0×1.02、PV＝C1÷0.08。

来期CFと価値は？

答えと考え方を見る

10.2万円、127.5万円です。
