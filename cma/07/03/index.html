企業行動・生産・費用・利潤最大化

企業は「売上が増えるか」だけでなく、「もう1単位作ることで収入と費用がいくら増えるか」を比べます。固定費・変動費・平均費用・限界費用を順に整理し、利潤最大化と操業判断をつなげます。

教材番号 7-03 · CORE · 更新・基準確認：2026年9月24日 · 動画：約10分を予定（未収録）

この講義のゴール

売上・固定費・変動費から利潤と損益分岐点を計算し、MR＝MCによる生産量選択、短期の操業停止と長期の退出を区別できる。

1. 作れば作るほど得、ではない

利潤πは総収入TR−総費用TCです。総費用は固定費FCと変動費VCに分かれます。平均費用AC＝TC/Qは全体を1単位当たりに均した値、限界費用MCは生産を追加したときの費用増加です。役割が違います。

2. 具体例：利潤と損益分岐点

価格10、単位変動費6、固定費200とします。数量Qの利潤はπ＝10Q−（200＋6Q）＝4Q−200です。Q＝100なら売上1,000、変動費600、総費用800、利潤200です。

3. 利潤最大化はMRとMCを比べる

追加生産の判断では全体平均のACではなく、追加収入MRと追加費用MCを比べます。MR＞MCなら増産で利潤が増え、MR＜MCなら減産で利潤が増えるため、内点の基本条件はMR＝MCです。

4. 赤字でも操業する場合がある

短期には固定費が回避できない場合があります。価格Pが平均総費用ACを下回って赤字でも、平均変動費AVCを上回るなら、操業によって変動費と固定費の一部を回収できます。P＜AVCなら、生産するほど回避可能な損失が増えるため操業停止を検討します。

5. 企業分析で確認する情報

現実の費用には段階的な設備投資、稼働率、在庫、学習効果があり、単純な直線ではありません。限界費用は財務諸表に直接表示されないため、数量・単価・原価構造・設備余力を組み合わせて推定します。

練習問題

必要な条件・数値・計算式は各問に記載しています。計算問題は電卓を使って構いません。本サイト独自の問題で、公式試験問題ではありません。

問1：利潤と損益分岐

ある製品の価格は12、1単位当たり変動費は7、固定費は300とします。

Q100の利潤と損益分岐数量は？

答えと考え方を見る

Q100の利潤は1,200−700−300＝200。損益分岐は300÷（12−7）＝60単位です。

問2：追加生産の判断

現在の数量でMR＝9、MC＝7。次の1単位でも他条件は大きく変わらないとします。

増産・減産のどちらが利潤を増やしますか。

答えと考え方を見る

MR＞MCなので増産方向です。交点へ近づくまで追加利潤が正です。

問3：本試験レベル：操業停止

短期の価格P＝70、平均総費用AC＝90、平均変動費AVC＝50。固定費は短期には回避不能です。

1つ選んでください。

答えと考え方を見る

正解は2。1単位当たり20だけ固定費回収へ寄与します。1は短期停止と長期退出を混同、3はMRとMCの情報がなく増産判断はできません。
