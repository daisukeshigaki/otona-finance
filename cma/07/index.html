7章：市場と経済の分析（21講義）

全21講義の記事・図表・練習問題を公開しました。動画は撮影後に追加します。

講義カリキュラム

  1. 第1回：需要・供給・市場均衡・弾力性

    コンビニの値上げで販売量が減ったとき、「価格が上がったから同じ需要曲線上を動いた」のか、「所得や好みが変わって需要曲線自体が動いた」のかで意味は異なります。まず市場の図の読み方から整理します。教材番号 7-01

    →
  2. 第2回：消費者行動・効用最大化

    予算1,000円でXとYを買うとき、予算内に収まる組合せは多数あります。その中でどれを選ぶかを決めるのが「好み＝選好」です。予算線と無差別曲線を重ねて、最適消費を順に理解します。教材番号 7-02

    →
  3. 第3回：企業行動・生産・費用・利潤最大化

    企業は「売上が増えるか」だけでなく、「もう1単位作ることで収入と費用がいくら増えるか」を比べます。固定費・変動費・平均費用・限界費用を順に整理し、利潤最大化と操業判断をつなげます。教材番号 7-03

    →
  4. 第4回：完全競争・独占・寡占・独占的競争

    「競合が多いか少ないか」だけでは企業の価格決定力は分かりません。参入障壁、製品差別化、競合の反応を加え、完全競争・独占・寡占・独占的競争を比較します。教材番号 7-04

    →
  5. 第5回：外部性・公共財・市場の失敗

    工場が製品を作るとき、企業が支払う原材料費だけでなく、周辺住民が負う騒音や汚染の損害が生じることがあります。市場価格に入らない第三者への影響から、市場の失敗と政策を理解します。教材番号 7-05

    →
  6. 第6回：GDP・国民所得勘定

    GDPは一定期間に国内で生み出した付加価値です。具体例と条件を変えた例で、GDP・国民所得勘定を学ぶ。教材番号 7-06

    →
  7. 第7回：景気循環・景気指標

    景気循環は拡張と後退等の経済活動の変動です。具体例と条件を変えた例で、景気循環・景気指標を学ぶ。教材番号 7-07

    →
  8. 第8回：インフレ・デフレ・物価指数

    物価指数は価格を一定の方式で集約したものです。具体例と条件を変えた例で、インフレ・デフレ・物価指数を学ぶ。教材番号 7-08

    →
  9. 第9回：失業・フィリップス曲線

    →
  10. 第10回：貨幣・銀行・信用創造

    銀行貸出は貸出資産と預金負債を生むことで信用創造に関わります。具体例と条件を変えた例で、貨幣・銀行・信用創造を学ぶ。教材番号 7-10

    →
  11. 第11回：中央銀行・金融政策・政策金利
