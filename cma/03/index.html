3章：株式分析・企業価値評価（28講義）

全28講義の記事・図表・練習問題を公開しました。動画は撮影後に追加します。

講義カリキュラム

  1. 第1回：資本市場・株式の種類・株主権

    株式は会社の所有持分を表す。普通株・優先株の権利と、株主が最後に受け取る仕組みを確認する。教材番号 3-01

    →
  2. 第2回：発行市場・流通市場・市場参加者

    新株を発行する市場と、既存株を売買する市場はお金の行き先が違う。参加者の役割を整理する。教材番号 3-02

    →
  3. 第3回：株価指数：TOPIX・日経平均・海外主要指数

    TOPIXと日経平均は、同じ日本株でも重みが違う。指数の上昇を個々の企業の上昇と取り違えない。教材番号 3-03

    →
  4. 第4回：現物・信用取引・清算・受渡

    約定したら終わりではない。現物・信用取引と、清算・受渡までの資金と証券の流れを確認する。教材番号 3-04

    →
  5. 第5回：成行・指値、オーダードリブン／クォートドリブン

    成行は価格を保証せず、指値は約定を保証しない。注文板から価格優先・時間優先を考える。教材番号 3-05

    →
  6. 第6回：産業分析：トップダウン／ボトムアップ

    景気から業種を選ぶか、会社から調べるか。どちらも事業の売上・費用・資本へつなげる。教材番号 3-06

    →
  7. 第7回：産業ライフサイクル・競争優位・戦略分析

    成長期・成熟期で競争と投資の条件は違う。競争優位が続く理由を、利益率と資本へ落とす。教材番号 3-07

    →
  8. 第8回：ESG・非財務情報・エンゲージメント

    ESG情報を点数で終わらせない。環境・人材・統治が売上・費用・資本・リスクへどう効くかを見る。教材番号 3-08

    →
  9. 第9回：株価・時価総額・EVの違い

    一株の値段、株主全体の値段、事業の値段は違う。EVから株式価値への橋を自分で作る。教材番号 3-09

    →
  10. 第10回：PER・PBR・PCFR・PSR・EV/EBITDA

    PER・PBR・PSRなどを同じ会社で並べる。安い比率が割安の証明にならない理由まで整理する。教材番号 3-10

    →
  11. 第11回：DDMの全体像

    配当を現在へ割り引いて株式価値を求める。保有期間の最後の売却価格も、未来の配当とつながっている。教材番号 3-11

    →
  12. 第12回：ゴードン成長モデル

    一定成長の配当を一本の式にまとめる。D0とD1、Keとgの差が価値を大きく変える。教材番号 3-12

    →
  13. 第13回：多段階DDM・インプライド成長率

    最初は高成長、やがて安定成長へ。詳細配当とターミナル価値をつなぎ、価格が織り込む成長も逆算する。教材番号 3-13

    →
  14. 第14回：サステイナブル成長率・ROE・配当性向

    ROEと留保率から配当成長を作る。高い留保が価値を生むのは、再投資の収益率が十分なとき。教材番号 3-14

    →
  15. 第15回：PVGOと成長機会

    株価のうち、既存の稼ぐ力と成長機会はいくらか。成長するだけで価値が増えるわけではない。教材番号 3-15

    →
  16. 第16回：FCFF・FCFEの算出と違い

    事業が生むFCFFと、株主に残るFCFEは違う。利益から投資と借入まで順に調整する。教材番号 3-16

    →
  17. 第17回：DCF：売上・利益率・運転資本・Capex予測

    DCFのCFをどこから作るか。売上・利益率・運転資本・設備投資を同じ予測表につなぐ。教材番号 3-17

    →
  18. 第18回：ターミナルバリューと感応度分析

    DCFの大半を終価が占めることがある。永続成長・割引率・出口倍率の前提を表で確かめる。教材番号 3-18

    →
  19. 第19回：残余利益モデルとPBR

    簿価に将来の超過利益を足して評価する。PBRとROE、株主資本コストの関係を理解する。教材番号 3-19

    →
  20. 第20回：マルチプル法・類似企業比較

    似た会社の倍率を使う。でも業種名が同じだけでは足りない。成長・採算・負債・会計差を調整する。教材番号 3-20

    →
  21. 第21回：成長企業・赤字企業・景気敏感株・資産株

    赤字成長企業、景気敏感企業、資産を多く持つ企業。同じPERを当てず、利益と資産の意味からモデルを選ぶ。教材番号 3-21

    →
  22. 第22回：株式リスクプレミアム・ベータ推計・割引率選択

    割引率は小さな入力差でも価値を変える。市場プレミアムとベータの推計条件、CFとの対応を確認する。教材番号 3-22

    →
  23. 第23回：市場効率性と株式運用戦略

    公開情報から簡単に儲かるのか。市場効率性の三形態と、アクティブ・パッシブ運用の条件を考える。教材番号 3-23

    →
  24. 第24回：株式ファクター・スマートベータ・投資スタイル

    バリュー・サイズ・モメンタムなどの共通特性で株をまとめる。ファクター収益と運用者の能力を分ける。教材番号 3-24

    →
  25. 第25回：トレーディング・HFT・アルゴ取引

    注文を分けるアルゴリズムと、高速に売買するHFTは同じ意味ではない。目的・費用・障害リスクを整理する。教材番号 3-25

    →
  26. 第26回：執行コスト：IS・VWAP・スプレッド

    予測が当たっても、売買コストで利益は減る。IS・VWAP・スプレッドを同じ注文から計算する。教材番号 3-26

    →
  27. 第27回：実践：1社をゼロからバリュエーション

    一社を調べ、CFを作り、一株価値まで計算する。実績・予測・価格を分けた独自の評価演習。教材番号 3-27

    →
  28. 第28回：会社法・金融商品取引法・株式市場ルール

    株主権・情報開示・禁止取引は別のルール。会社法・金融商品取引法・取引所制度を分けて確認する。教材番号 3-28

    →
