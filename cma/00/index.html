0章：投資と企業価値の地図（4講義＋導入）

会社に資金が集まり、事業が価値をつくり、投資家にリターンが届く。その一連の流れを4講義で学びます。

公開中の講義

  1. 0-0：CMAの全体像と学習方法

    試験制度、全11章・本編212講義の地図、動画と演習を組み合わせた学び方を整理する。教材番号 0-0／導入

    →
  2. 第1回：株式会社はなぜ存在するのか／株主・債権者・経営者

    出資と借入、所有と経営の分離、株主に残る価値を整理する。教材番号 0-01

    →
  3. 第2回：企業価値創造：ROIC・成長・資本コスト

    ROICとWACCを比べ、利益の成長が価値創造につながる条件を学ぶ。教材番号 0-02

    →
  4. 第3回：投資とは何を買うのか：キャッシュフローと期待

    将来キャッシュフロー・価格・市場の期待を分けて投資を考える。教材番号 0-03

    →
  5. 第4回：株式・債券・現金・デリバティブを一枚で整理

    4つの金融商品を、権利・キャッシュフロー・リスクで比較する。教材番号 0-04

    →
