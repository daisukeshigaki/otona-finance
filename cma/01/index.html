1章：財務会計・財務分析（28講義）

全28講義の記事・図表・練習問題を公開しました。動画は撮影後に追加します。

講義カリキュラム

  1. 第1回：PL・BS・CFのつながりを完全に理解する

    同じ会社の取引を、利益・財産・現金の三つの角度で記録する。黒字なのに資金が減る理由まで追います。教材番号 1-01

    →
  2. 第2回：売上・原価・販管費：利益率は何で決まるか

    利益率を価格・販売量・原価・販管費へ分解し、増収でも減益になるケースを計算する。教材番号 1-02

    →
  3. 第3回：営業利益・EBITDA・EBT・純利益・NOPAT

    似ている利益指標を、何を引いた後の数字なのかで整理する。EBITDAと現金も区別します。教材番号 1-03

    →
  4. 第4回：運転資本：売掛金・買掛金・在庫・契約負債

    売掛金・在庫・買掛金・前受の増減から、売上の成長に必要な資金を見積もる。教材番号 1-04

    →
  5. 第5回：設備投資・減価償却・固定資産・減損

    設備代を払う時期と費用を計上する時期の違い、減損が利益とCFへ与える影響を学ぶ。教材番号 1-05

    →
  6. 第6回：のれん・無形資産・PPA・M&A会計

    買収代金を資産・負債・のれんへ分解し、買収後の利益に償却や減損が出る理由を学ぶ。教材番号 1-06

    →
  7. 第7回：リース会計：使用権資産・リース負債

    借りた設備の利用権と将来の支払義務をBSへ載せると、利益・CF・財務指標がどう変わるか。教材番号 1-07

    →
  8. 第8回：引当金・退職給付・繰延税金

    支払前の費用や会計と税務の時期差を、引当金・退職給付・繰延税金として整理する。教材番号 1-08

    →
  9. 第9回：営業CF・投資CF・財務CFと三表連動

    営業・投資・財務の三つのCFを並べ、借入で現金を増やした会社と営業で増やした会社を区別する。教材番号 1-09

    →
  10. 第10回：財務報告制度・開示制度・監査・会計基準

    決算短信・有報・監査・会計基準を整理し、どの数字をどの資料で確認するかを学ぶ。教材番号 1-10

    →
  11. 第11回：収益認識：履行義務・契約資産・契約負債

    契約を結んだ日、請求した日、入金した日と、売上を認識する日は同じとは限らない。教材番号 1-11

    →
  12. 第12回：金融商品会計：有価証券・公正価値・減損

    保有目的や契約の性質で金融資産の測定が変わる。時価変動が利益かOCIかを整理する。教材番号 1-12

    →
  13. 第13回：デリバティブ会計・ヘッジ会計の基本

    先物・スワップ等の評価損益と、リスク管理の対象の損益の時期を合わせる考え方を学ぶ。教材番号 1-13

    →
  14. 第14回：連結会計：連結範囲・内部取引消去・非支配持分

    親子会社を一つの経済単位として示すとき、内部売上や内部利益が消える理由を学ぶ。教材番号 1-14

    →
  15. 第15回：持分法・関連会社・共同支配

    支配していないが重要な影響力がある投資先は、売上全額でなく持分に対応する損益を反映する。教材番号 1-15

    →
  16. 第16回：外貨換算・在外子会社・為替換算調整

    外貨建債権の為替損益と、海外子会社を円へ換算する調整を別々に整理する。教材番号 1-16

    →
  17. 第17回：包括利益・OCI・リサイクリング

    純利益の外にも純資産を動かす項目がある。包括利益とOCI、振替の意味を学ぶ。教材番号 1-17

    →
  18. 第18回：EPS・希薄化EPS・株式報酬

    一株当たり利益は利益だけでなく株数でも動く。潜在株式と株式報酬を含めて読む。教材番号 1-18

    →
  19. 第19回：ROE・ROA・ROICとデュポン分解

    利益率・資産回転・財務レバレッジへ分解して、ROEが高い理由を探る。教材番号 1-19

    →
  20. 第20回：安全性・流動性：流動比率・当座比率・D/E・ICR

    短期の支払能力と長期の財務負担を、複数の比率で点検する。教材番号 1-20

    →
  21. 第21回：CCC・各種回転率・資本効率

    商品を仕入れてから代金を回収するまで、何日分の資金を持つ必要があるかを計算する。教材番号 1-21

    →
  22. 第22回：利益の質：会計利益とキャッシュのズレ

    純利益と営業CFの差から、成長に必要な資金、見積り、一時利益の影響を探る。教材番号 1-22

    →
  23. 第23回：業種別BS/PL/CFの特徴

    小売・製造・サービス・金融で三表の形が違う。比率のランキング前に事業モデルを読む。教材番号 1-23

    →
  24. 第24回：セグメント分析・事業別収益性・SOTP

    事業ごとに利益率と資本効率を読み、部門価値を積み上げるSOTPの入口まで進む。教材番号 1-24

    →
  25. 第25回：実践：決算短信・有報で企業を10分分析

    実際の決算短信で対象期間・利益率・CFを確認し、有報で深掘りする問いを作る。教材番号 1-25

    →
  26. 第26回：棚卸資産・費用認識・繰延べ／見越し

    仕入と売上原価、支払と費用を分け、期末調整が利益とBSへどう表れるかを学ぶ。教材番号 1-26

    →
  27. 第27回：純資産会計・株主資本等変動計算書・分配規制

    利益蓄積・増資・配当・自己株買いを区別し、純資産と配当可能額の違いを学ぶ。教材番号 1-27

    →
  28. 第28回：損益分岐点・固定費／変動費・付加価値・生産性分析

    固定費・変動費を分け、黒字化に必要な売上と価格変化への感度を計算する。教材番号 1-28

    →
