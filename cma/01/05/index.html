設備投資・減価償却・固定資産・減損

設備代を払う時期と費用を計上する時期の違い、減損が利益とCFへ与える影響を学ぶ。

教材番号 1-05 · CORE · 更新・基準確認：2026年9月17日 · 動画：約10分を予定（未収録）

この講義のゴール

固定資産の残高を投資・償却・売却・減損でつなぎ、基準差を区別できる。

1. 購入日に全額費用とは限らない

何年も使用する設備を取得した場合、資産として計上し、使用期間へ費用配分するのが減価償却です。購入代金の支払いは投資CF、償却費はPLの費用です。費用化と支払いのタイミングを分けることで、一年の利益と長期の設備投資を同時に理解できます。

この例は取得直後から通年使用し、月割り・税務・消費税を省略します。会計上の耐用年数は経済的な使用見込み、税務上の償却は法令の条件によるため、必ず一致するとは限りません。土地は通常償却しない点も建物や機械と区別します。

2. 期末固定資産をつなぐ

売却代金70なら、売却益は70−帳簿価額50＝20、投資CFは＋70です。固定資産を70減らすのではありません。帳簿から消す金額と受け取った代金の差が損益になります。買収・為替・リース・建設仮勘定などを含む実際の注記では、増減表の項目を追加して照合します。

3. 減損は将来回収の見直し

IFRSの簡略例で帳簿300、処分コスト控除後公正価値220、使用価値250なら回収可能価額250、減損50です。日本基準にこの判定をそのまま当てはめず、認識の段階を別に考えます。のれんや耐用年数を確定できない無形資産等では、毎年の検討が必要になる点にも注意します。

4. 非現金費用でも悪化の情報はある

減損を足し戻すから影響ゼロ、とはいえません。現金は当期に減らなくても、将来CF見積もりの悪化を示します。設備投資額と償却費の比率は参考になりますが、成長投資・維持投資・リース・物価上昇を切り分けなければ、償却費をそのまま必要更新投資額とみなすことはできません。

練習問題 — この場の資料だけで解く

必要な条件・数値・計算式は各問に記載しています。計算問題は電卓を使って構いません。本サイト独自の問題で、公式試験問題ではありません。

問1：定額償却

取得価額300万円、残存価額0、耐用年数5年、通年使用。年償却＝（取得−残存）÷年数。

年償却と一年後純額は？

答えと考え方を見る

償却60万円、純額240万円です。

問2：売却

帳簿価額50、売却代金70（万円）。手数料・税なし。売却益＝代金−帳簿価額、入金は投資CF。

利益とCFは？

答えと考え方を見る

売却益20万円、投資CF＋70万円。

問3：IFRS減損

IAS 36の簡略例。帳簿300、処分コスト控除後公正価値220、使用価値250（万円）。回収可能価額は後二者の高い方、減損＝帳簿−回収可能価額。

減損額は？

答えと考え方を見る

回収可能価額250、減損50万円です。
