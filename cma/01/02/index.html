売上・原価・販管費：利益率は何で決まるか

利益率を価格・販売量・原価・販管費へ分解し、増収でも減益になるケースを計算する。

教材番号 1-02 · CORE · 更新・基準確認：2026年9月17日 · 動画：約10分を予定（未収録）

この講義のゴール

粗利率と営業利益率を区別し、価格と費用の変化が利益へ与える影響を説明できる。

この講義で学ぶこと

  2. PLを一覧で比較する
  3. 価格と数量を別々に動かす
  4. 利益率の原因を注記へつなぐ
  5. 練習問題
  6. まとめ

1. 売上が増えるだけでは足りない

売上高は、おおむね単価×販売数量です。売上原価は売れた商品やサービスに対応する費用、販管費は販売活動や会社運営の費用です。製造業の工場人件費と本社人件費のように、同じ給与でも機能により分類が変わります。何を売っている会社なのかを先に確認します。

以下の金額は架空の店舗会社です。値引きで数量が増えても、一個当たりの粗利が下がれば利益が伸びるとは限りません。売上原価と仕入支払額も同じではありません。在庫や買掛金の変化は、利益率の分析とは別に確認します。

2. PLを一覧で比較する

売上は20％増えたのに営業利益は20％減っています。粗利は20増えましたが、販管費が50増えたため差引30減益です。売上の増加だけを見て「好調」と決めるのではなく、どの段階の利益が増減したかを順にたどります。金額と率を両方並べると、規模の効果と採算の悪化を切り分けられます。

3. 価格と数量を別々に動かす

値引き後は数量20％増ですが、単価は10％下がります。粗利を40万円に保つには、40万円÷（900−600）＝約1,333.33個、整数なら1,334個以上必要です。販管費が固定なら粗利の差がそのまま営業利益の差へ移ります。実際には商品構成、仕入値、人員増加なども変化するため、条件を一つずつ追加します。

4. 利益率の原因を注記へつなぐ

原価率の上昇をすべて原材料高と断定してはいけません。販売構成や工場稼働率でも変わります。比較対象は同じ期間・連結範囲・会計基準にそろえ、単なる推測と会社が説明している事実を分けて書きます。利益率が高い会社でも、資産を多く使えば資本効率が高いとは限らず、第19回のROICへつながります。

練習問題 — この場の資料だけで解く

必要な条件・数値・計算式は各問に記載しています。計算問題は電卓を使って構いません。本サイト独自の問題で、公式試験問題ではありません。

問1：営業利益率

売上1,200、原価780、販管費300（万円）。営業利益＝売上−原価−販管費、利益率＝営業利益÷売上。

営業利益と利益率は？

答えと考え方を見る

120万円、10％です。粗利420万円・35％とは区別します。

問2：値引き後の粗利

単価900円、数量1,200個、一個原価600円。粗利＝（単価−原価）×数量。

粗利は？

答えと考え方を見る

300×1,200＝36万円です。

問3：必要販売量

単価900円、一個変動原価600円、目標粗利40万円。必要量＝目標粗利÷一個粗利。整数切上げ。

何個必要？

答えと考え方を見る

400,000÷300＝1,333.33…なので1,334個です。
